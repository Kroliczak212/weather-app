# Weather App 🌦️

Aplikacja pogodowa umożliwiająca wyszukiwanie prognozy pogody dla dowolnego miasta. 
Wykorzystuje API OpenWeather do pobierania danych takich jak aktualna temperatura, 
prognoza na kolejne dni oraz godziny wschodu i zachodu słońca.

## 📋 Funkcjonalności
- Wyszukiwanie miast i wyświetlanie aktualnych warunków pogodowych (temperatura, wilgotność, prędkość wiatru).
- Wyświetlanie prognozy pogody na kolejne dni.
- Prezentacja godzin wschodu i zachodu słońca w lokalnej strefie czasowej miasta.


## 🛠️ Technologie
- **React** – Komponenty funkcyjne.
- **Vite** – Szybkie budowanie aplikacji.
- **CSS Modules** – Stylizacja aplikacji.
- **OpenWeather API** – Pobieranie danych pogodowych.
